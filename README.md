# Rose Gold Nikkah Invitation

A luxury pink wedding invitation experience for Huzaifa and Bismah.

## Project notes

- Full-screen invitational landing experience
- Envelope opening animation with a royal palace backdrop
- Scroll-based storytelling layout with romantic details
- Music starts after the envelope opens
- No visual redesign was made beyond the existing project styling
