# Rose Gold Nikkah Invitation

A luxury pink wedding invitation experience for Muhammad Huzaifa Alam and Bisma Ajmal Khan.

## Project notes

- Interactive envelope opening with a royal palace backdrop
- A skip-ready envelope reveal, Arabic Bismillah, welcome, Dua, event details, and live countdown
- Calendar options for Google Calendar and downloadable Apple/Outlook-compatible `.ics` files
- Nikkah: Sunday, 13 December 2026 at 1:00 PM PKT; venue to be announced
- Optional music that starts after the invitation is opened

## Development

```sh
npm install
npm run dev
```

## Build and deploy

```sh
npm run build
npm run preview
```

This is a client-side React app built with Vite. Deploy the generated `dist/`
directory to Vercel or another static hosting provider.
